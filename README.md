# Aviation Impact & Action Dashboard

A comprehensive aviation decision support system for Kenyan airports and airstrips.

## Features
- Real-time weather data visualization
- Role-based access control
- Impact assessment and action recommendations
- NetCDF forecast data support
- Alert and notification system
- PDF report generation

## Prerequisites
- Docker Desktop
- Node.js 18+
- Git
